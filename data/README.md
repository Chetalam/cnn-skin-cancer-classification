# Datasets

Datasets are not stored in this repository due to file size.

HAM10000
- Source: https://www.kaggle.com/datasets/kmader/skin-cancer-mnist-ham10000
- Size: approximately 2.5 GB
- Images: 10,015 dermoscopy images
- Classes used: mel, bcc, akiec (SCC)

PAD-UFES-20
- Source: https://www.kaggle.com/datasets/mahdavi1202/skin-cancer
- Size: approximately 560 MB
- Images: 2,298 clinical images
- Classes used: MEL, BCC, SCC
